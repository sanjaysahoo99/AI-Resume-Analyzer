# 🤖 AI Resume Analyzer

An AI-powered web application that analyzes resumes against job descriptions to calculate an **ATS (Applicant Tracking System) compatibility score**, identify missing skills, and provide actionable improvement suggestions.

> **Developed by Captain Sanjay**

---

## ✨ Features

- 📄 Upload Resume (PDF)
- 💼 Compare with Job Description
- 📊 ATS Compatibility Score
- 🧠 Resume Skill Analysis
- 🔍 Missing Skills Detection
- 💡 Resume Improvement Suggestions
- 🎨 Modern & Responsive UI

---

## 🛠️ Tech Stack

- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, JavaScript
- **Libraries:** PyPDF2, Scikit-learn

---

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/sanjaysahoo99/AI-Resume-Analyzer.git
cd AI-Resume-Analyzer
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the project

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```
